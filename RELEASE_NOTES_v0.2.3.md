# Arachn0de v0.2.3 Beta

## Novedades

- Recurrencia de tareas y obligaciones; Calendario con vistas Hoy, Semana y Mes y filtros.
- Etiquetas, prioridad, historial y Atención mejorada.
- Creación y edición renovadas, recuperación de borradores y deshacer creación individual o múltiple.
- Selección múltiple, mover/eliminar en conjunto y edición de grupos de creación.
- Navegación móvil adaptativa, acciones visuales consistentes y copia de Proyectos.
- Ordenación contextual de elementos y valores predeterminados globales, por Proyecto y por Capa, con herencia.

## Datos y compatibilidad

La actualización desde v0.2.2 incorpora migraciones locales para conservar los datos existentes. Backup lógico v7, con lectura de formatos anteriores v1–v6. La instalación debe conservar la firma oficial; la comprobación del APK firmado y la actualización física siguen pendientes de las credenciales de firma.

## Beta

Recomendamos crear y conservar un backup antes de actualizar. Este documento es un borrador para revisión; la Release todavía no está publicada.
