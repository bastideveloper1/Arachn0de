# Local social icons

`ic_social_github.xml`, `ic_social_instagram.xml` and `ic_social_mastodon.xml`
contain unchanged SVG paths from [Simple Icons 13.21.0](https://github.com/simple-icons/simple-icons/tree/13.21.0/icons), converted to Android VectorDrawable wrappers.

- [GitHub source](https://github.com/simple-icons/simple-icons/blob/13.21.0/icons/github.svg)
- [Instagram source](https://github.com/simple-icons/simple-icons/blob/13.21.0/icons/instagram.svg)
- [Mastodon source](https://github.com/simple-icons/simple-icons/blob/13.21.0/icons/mastodon.svg)

Simple Icons distributes these paths under CC0 1.0 Universal; the license is
preserved in [design/licenses/simple-icons-CC0.md](design/licenses/simple-icons-CC0.md).
Brand names and trademarks belong to their respective owners. Icons identify
external profile links and do not imply affiliation. No runtime icon downloads.
Web uses the existing Material Language icon. Arachn0de's official logo is unchanged.
